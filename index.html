About this project

Independent scientific research workspace.

Bangladesh Eulophidae Database

This project is a prototype for compiling taxonomic evidence on Eulophidae found in Bangladesh. It is not an official GBIF site, national checklist or peer-reviewed taxonomic resource.

Live taxonomic search and public occurrence data are provided by the Global Biodiversity Information Facility. Species names should be rechecked against the Universal Chalcidoidea Database and original publications. Background tiles are © OpenStreetMap contributors.

Privacy & validation: Private specimen and bibliography data are stored in Supabase with a restricted administrator policy. Public visitors access only GBIF data. Secure configuration, RLS and HTTPS are required before publishing. Keep offline backups.

Open data: Public records should retain their dataset attribution, occurrence IDs and licensing metadata. Link to original GBIF records when publishing scientific evidence.
